# Qué fuentes se citan en un informe

## Cuatro preguntas para cualquier fuente

1. **¿Quién lo dice?** Un autor con nombre, una institución o un organismo. Sin autor, no se
   cita.
2. **¿Dónde está publicado?** Una revista, una editorial, un repositorio universitario, la
   página oficial del organismo.
3. **¿Cuándo?** Tiene fecha. Para datos (cifras, estadísticas) conviene que sea de los
   últimos cinco años; para teorías, vale el autor clásico.
4. **¿Para qué lo publicó?** Informar o investigar, no vender.

Si falla una de las cuatro, se busca otra.

## Casos que llegan siempre

- **Wikipedia.** Sirve para entender un tema y para encontrar las fuentes que cita al pie.
  Se cita la fuente del pie, no Wikipedia.
- **ChatGPT u otra IA.** No es una fuente: no tiene autor ni se puede verificar, y a veces
  inventa. Si dio un dato, se busca el dato en su fuente original.
- **Monografías.com, Brainly, Scribd, «resúmenes».** Trabajos de otros estudiantes sin
  revisión. No se citan.
- **Un video de YouTube.** Solo si es de una institución identificable (una universidad, un
  organismo) y el dato no está en otro formato. Mejor buscar el documento.
- **Una noticia.** Vale para un hecho reciente, de un medio conocido. No para teoría ni para
  cifras que tienen fuente oficial.
- **Diapositivas del docente.** Si el docente las dio como material del curso y la consigna
  lo permite, se pueden usar; lo ideal es citar el libro del que salen.
- **Tesis.** De repositorios universitarios (RENATI en Perú, repositorios de cada
  universidad). Valen como antecedente; no reemplazan a un libro o artículo.

## Dónde buscar, además de las herramientas

| Qué | Dónde |
|---|---|
| Artículos en español | SciELO, Redalyc, Dialnet, Google Académico |
| Estadísticas del Perú | INEI, BCRP, ministerios |
| Datos internacionales | OIT, CEPAL, Banco Mundial, OMS |
| Normas y leyes | El Peruano, SPIJ, página del organismo |
| Tesis | RENATI, repositorios de cada universidad |

Lo que se encuentre ahí se guarda en Zotero, en Mendeley o en «Mis fuentes» para que tenga clave.
